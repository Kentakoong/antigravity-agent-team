# Example teams

Each folder contains a team's agents and Skills under `.agents/`.

| Example | What it does |
| --- | --- |
| [Lecture study guide](lecture-study-guide-team/) | Turns lecture slides into a Markdown study guide with recall quizzes and an independent source-fidelity review. |
| [Blog post](blog-post-team/) | Researches a topic, drafts a blog post, and independently reviews it. |
| [Data analysis](data-analysis-team/) | Profiles tabular data, writes an analysis report, and independently checks its claims against the dataset. |
| [Research brief](research-brief-team/) | Investigates a question, writes a concise brief, and independently checks facts and citations. |
