# Gemini screenshots

These images are cropped from the screenshots supplied for the workshop. They show setup, quiz-team generation, downloading a file and adding HTML. The original screenshots are unchanged; no text or interface details were generated.

[CROP-MANIFEST.json](CROP-MANIFEST.json) records the source files, crop locations and file checksums. The images_raw folder supplied the initial set; the Download example came from a later attachment.

See [the example Gemini conversation](https://gemini.google.com/app/db985e0c4d7b9dbf). These images show Gemini's responses, not a tested Antigravity result.
